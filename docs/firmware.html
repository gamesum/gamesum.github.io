My controller isn't showing up when I click Connect

Make sure it's plugged in with a data-capable USB-C cable — charge-only cables won't show a port. Try a different USB port, and close any other program (like a serial monitor) that might already have the port open. Some boards need you to hold BOOT, press and release RST, then release BOOT before they'll appear.

How do I find my controller's IP address, for the Wi-Fi option?

Open the AFTERGLO app, tap your controller, and its IP address is shown in its device details. You can also check your Wi-Fi router's connected-devices list for a device named "AFTERGLO" or similar.

Which fixture type do I pick?

Whichever this specific controller drives: your roofline lighting, an arch, or a tree. If you have more than one controller for different fixtures, you'll need to repeat this for each one.

Will this erase my settings?

No. This only replaces the running application firmware — the same thing the app does when it updates your controller. Wi-Fi credentials, presets, and pixel layout are untouched.

Questions

Firmware FAQ.

Is this really the same firmware the app installs?

Yes. This page fetches the exact same release feed the AFTERGLO app checks, so it's never behind. Both check the file's checksum before trusting it.

Why does the Wi-Fi option make me upload the file myself?

Browsers block a secure page like this one from directly talking to a plain, unencrypted address on your home network — that's a security protection, not something we can turn off. Verifying and downloading the file for you is what this page can safely do over Wi-Fi; the last step of handing it to your controller has to happen on your controller's own page. USB skips this entirely since your browser talks straight to the controller.

Does flashing over USB erase my settings?

No. It only rewrites the two firmware slots your controller boots from — never the bootloader, never your saved settings. Wi-Fi credentials, presets, and pixel layout are stored separately and untouched.

Does this send anything about my controller to AFTERGLO?

No. This page only downloads a public firmware file and checks its checksum in your browser — it never talks to your controller directly, and we don't learn anything about your device from using it.
