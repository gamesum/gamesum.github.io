Flash From Your Browser

Plug your controller into this computer with a USB-C cable, click the button below, and select it from the port list. The tool reads your controller's chip automatically and only writes firmware built for it.

Supports the AFTERGLO Controller (ESP32-S3) via its native USB-C port.
Your browser doesn't support Web Serial. Use Google Chrome or Microsoft Edge on a desktop or laptop computer.
This page needs to be loaded over HTTPS to flash a device. Try reloading at https://afterglolighting.org/firmware.html.

Choosing "Erase and factory reset" inside the dialog will also clear your Wi-Fi credentials, presets, and pixel layout — only use it to recover a controller that won't boot.

Update Over Wi-Fi Instead

If your controller is already online and running AFTERGLO firmware, you can push an update from its own web page instead of using USB.

Enter a valid IPv4 address, like 192.168.1.42.

This opens http://<your-controller-ip>/update in a new tab. Your browser will flag it as "not secure" since it's a plain HTTP page served by the controller itself on your local network — that's expected.

My controller isn't showing up in the port list

Make sure it's in bootloader mode: hold BOOT, press and release RST, then release BOOT. Confirm you're using a data-capable USB-C cable — charge-only cables won't show a port. Try a different USB port, and close any other program (like a serial monitor) that might already have the port open.

Is my board supported?

This tool checks your controller's chip automatically and only proceeds if a matching build is available. Right now that's the AFTERGLO Controller (ESP32-S3). If you're on an older or third-party board, this tool isn't for you — reach out to us directly.

The flash failed partway through — is my controller bricked?

Almost certainly not. The bootloader lives in a protected region of the chip that this tool cannot overwrite. Put the board back into bootloader mode and try again. If it keeps failing, try a different USB cable or port before reaching out to us.

Questions

Firmware FAQ.

Will this erase my settings and light sequences?

No, not by default. "Connect & Install Firmware" only writes to the application partition — your Wi-Fi credentials, presets, and pixel layout are untouched. The dialog also offers a full erase option for recovering a controller that won't boot; that option does clear everything.

I only have Safari or Firefox — can I still update?

Not from this page. The Web Serial API this tool relies on is only available in Chromium-based browsers — Google Chrome or Microsoft Edge on a desktop or laptop. It isn't available on any mobile browser, including Chrome on Android or iOS. If your controller is already online, use the Over Wi-Fi option above instead.

Can I flash over Wi-Fi instead of USB?

Yes — once your controller is online and running AFTERGLO firmware, visit http://<controller-ip>/update to upload a firmware file directly from its own built-in updater. See the Over Wi-Fi card above.

Does this send anything about my controller to AFTERGLO?

No. The connection between your browser and your controller happens directly over USB using the Web Serial API — it never touches our servers. We only serve the static firmware files this page downloads to write to your device.
