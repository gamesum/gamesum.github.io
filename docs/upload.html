What is an FSEQ file?

An FSEQ (Falcon Sequence) file is the standard format used by xLights to store light show timing data. It contains a frame-by-frame record of every channel value for your entire sequence, essentially the "film reel" of your light show.

  • How to export from xLights: File → Export Sequence → FSEQ v2 (uncompressed)
  • Max file size: 50 MB
  • Version: FSEQ v2 (v1 is not supported)
  • Compression: Choose "None" (uncompressed) so the controller can stream it directly

The AFTERGLO controller streams the FSEQ file in real time, frame by frame, driving your roofline LEDs in perfect sync with your audio.
